# Iris Species Classification

A Machine Learning pipeline built with Python and Scikit-Learn to classify Iris flower species based on physical feature measurements.

---

## Overview

This project loads the Iris dataset, preprocesses categorical species labels, performs a train-test split, and trains classification models to predict flower species.

---

## Models Trained

* **Logistic Regression** (`LogisticRegression`)
* **K-Nearest Neighbors** (`KNeighborsClassifier`)

---

## Dataset Features

* `SepalLengthCm`
* `SepalWidthCm`
* `PetalLengthCm`
* `PetalWidthCm`
* `Species` *(Target)*

---

## Tech Stack & Dependencies

* **Python**
* **pandas**
* **scikit-learn**
